뉴스 도구 실행 방법

PowerShell에서 D:\llama_cpp\llama 폴더로 이동한 뒤 실행:
  .\run.cmd
또는:
  .\mcps\news\start-news.ps1

직접 실행하려면:
  .\llama-server.exe -m .\Ternary-Bonsai-2-27B-Uncensored-Heretic-PTQ1_0.gguf --host 127.0.0.1 --port 8080 --jinja --mcp-servers-config .\mcps\news\news-mcp.json

이미 8080 포트에 서버가 실행 중이면 기존 서버를 종료한 뒤 실행한다.
웹 UI: http://127.0.0.1:8080
기존에 열려 있던 웹 UI는 새로고침한다.
+ 메뉴 > Tools > Server에서 news_search_news를 활성화한다.
도구 사용 확인이 표시되면 Allow once를 누른다.

예시 질문:
  news_search_news 도구로 AI when:1d를 검색해서 최근 AI 뉴스 3건을 출처와 링크와 함께 한국어로 정리해줘. 제목에서 확인되는 내용만 요약해줘.
  news_search_news로 오늘 주요 뉴스 10건을 가져와 분야별로 정리해줘.

API 키나 추가 패키지 설치는 필요 없다. Windows PowerShell을 사용한다.
search_news는 Google News RSS의 제목, 출처, 발행시각을 수집한다.
Google 뉴스 중계 주소에서 원문 주소를 추출하고 HTTP 접속 상태를 확인한다.
url은 원문 주소가 있으면 원문이며, 없으면 Google 뉴스 중계 주소다.
url_kind와 link_status로 원문 여부 및 접속 상태를 구분한다.
citation을 답변에 그대로 붙여 넣도록 도구 설명에서 지시한다.
원문을 못 얻으면 원문 미확인으로 표시하며 주소를 추측하지 않는다.
HTTP 200은 본문 전체가 읽혔다는 뜻은 아니다.
원문 주소는 24시간 캐시하며, 검색당 주소 추출은 최대 45초로 제한한다.
Google의 비공식 주소 해석 방식이 변경되거나 차단되면 원문 해석이 실패할 수 있다.
원문 해석은 Codex 제공 Node.js 런타임을 사용한다.
기사 전문은 수집하지 않는다. 발행일이나 내용의 정확성은 원문에서 확인한다.
네트워크 오류는 도구 오류로 반환하며, 성공한 것처럼 결과를 만들지 않는다.
도구 사용과 요약 품질은 모델의 판단 및 웹 UI의 설정에도 영향을 받는다.
검색어는 Google News로 전송된다.

검증: MCP 초기화/도구 목록, 실제 RSS 검색, 서버 /health 및 /tools,
모델의 API tool_calls, 웹 UI의 도구 호출과 후속 요약을 확인했다.
