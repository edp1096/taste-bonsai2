웹검색 MCP

루트의 run.cmd를 실행하면 뉴스와 웹검색 도구가 함께 등록된다.
통합 설정: mcps/mcp-servers.json
웹검색 도구 이름: web_search_web
페이지 확인 도구 이름: web_fetch_web
뉴스 도구 이름: news_search_news

질문 예시:
  web_search_web 도구로 llama.cpp 공식 저장소와 설치 문서를 찾아 링크와 함께 정리해줘.

브라우저를 새로고침하고 + > Tools > Server에서 도구가 활성화되어 있는지 확인한다.
도구 실행 확인이 나타나면 Allow once를 누른다.

API 키나 추가 패키지 없이 Windows PowerShell로 동작한다.
DuckDuckGo HTML 검색을 기본으로 사용하며 실패하면 Bing RSS를 사용한다.
검색어는 검색 제공자에게 전송된다.
검색 결과는 제목, 링크, 검색 요약문이다.
web_fetch_web은 공개 URL의 제목과 본문 텍스트를 가져온다.
본문은 기본 8000자, 최대 20000자이며 잘림 여부를 반환한다.
JavaScript 실행, 로그인, PDF 읽기, 화면 클릭은 지원하지 않는다.
로컬/사설 주소 및 80/443 외의 포트는 지원하지 않는다.
검색 제공자의 차단, 결과 누락, HTML 구조 변경으로 실패할 수 있다.
오류 및 대체 제공자 사용 이유는 도구 결과에 반환한다.
검색 결과의 최신성 및 관련성은 모델이 구분해야 한다.
